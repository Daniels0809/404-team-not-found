# 404 Team - Not Found

Proyecto colaborativo del equipo 404 para trabajar en integraciones y desarrollar proyectos innovadores.

## 🎨 Diseño

- **Colores**: Tonos blanco y azul
- **Tipografía**: Poppins (Google Fonts)
- **Estilo**: Moderno, limpio y minimalista

## 📁 Estructura del Proyecto

```
404-Team-not-found/
├── index.html          # Página de inicio
├── about.html          # Vista sobre nosotros
├── projects.html       # Vista de proyectos
├── contact.html        # Vista de contacto
├── styles/
│   └── main.css       # Estilos principales
└── README.md          # Documentación
```

## 🚀 Inicio Rápido

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. ¡Listo para trabajar!

## 👥 Colaboración

Este proyecto está diseñado para trabajar en equipo. Cada miembro puede crear ramas feature para agregar nuevas funcionalidades e integraciones.

## 📝 Notas

- El proyecto usa HTML5 y CSS3 puro
- Diseño responsive y mobile-first
- Listo para integrar frameworks y librerías según sea necesario
